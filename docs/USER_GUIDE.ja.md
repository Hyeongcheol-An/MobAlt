# MobAlt ユーザガイド

このガイドの他言語版：[English](USER_GUIDE.md) · [한국어](USER_GUIDE.ko.md) · [简体中文](USER_GUIDE.zh-CN.md) · [日本語](USER_GUIDE.ja.md) · [Tiếng Việt](USER_GUIDE.vi.md) · [हिन्दी](USER_GUIDE.hi.md) · [Deutsch](USER_GUIDE.de.md) · [Français](USER_GUIDE.fr.md) · [Español](USER_GUIDE.es.md) · [Português](USER_GUIDE.pt.md)

MobAlt は macOS 向けの MobaXterm スタイルのワークベンチです。左にセッションツリー、中央にタブ分割できる
ターミナル、サイドパネルに SFTP ブラウザ・ネットワークツール・マクロを備えています。

関連：[MobaXterm 26.6 との機能対応表](MOBAXTERM_PARITY.md) — MobAlt にあるもの、ないもの、やり方が違うもの、そしてロードマップ。

## インストール

- **Homebrew**：`brew tap Hyeongcheol-An/tap && brew trust Hyeongcheol-An/tap && brew install --cask mobalt`
  （Homebrew 7 ではサードパーティの tap を一度信頼する必要があります。以後は `brew upgrade --cask mobalt` でアップデートできます）
- **DMG**：[Releases](https://github.com/Hyeongcheol-An/MobAlt/releases) から Apple Silicon（`arm64`）または
  Intel（`x64`）の DMG をダウンロードし、MobAlt をアプリケーションフォルダにドラッグします。

リリースは署名・公証済みです。要件：macOS 13 以降。あると便利なもの：
X11 転送には [XQuartz](https://www.xquartz.org/)、Mosh セッションには `brew install mosh`、
RDP には Windows App。

MobAlt は起動時に GitHub Releases で新しいバージョンを確認し、ダイアログで提示します。確認なしに
ダウンロードもインストールもされません。[アップデート](#アップデート)を参照してください。

## アップデート

新しいリリースへの道は 3 つあり、いずれも新しいバンドルが `/Applications/MobAlt.app` に置かれて終わります。

- **アプリ内アップデータ**：MobAlt は起動時に GitHub Releases を確認します（設定 → アップデートでオフにできます）。
  ヘルプ → アップデートを確認…、または設定 → アップデートの「今すぐ確認」で手動確認もできます。新しい
  バージョンはダイアログで提示され、あなたが指示したときだけダウンロードされ、終了時にインストールされます。
  「今すぐ再起動」を選べばすぐにインストールされます。
- **Homebrew**：`brew upgrade --cask mobalt` がアプリケーションフォルダのアプリを置き換えます。
- **DMG**：[Releases](https://github.com/Hyeongcheol-An/MobAlt/releases) から新しい DMG をダウンロードし、
  MobAlt をアプリケーションフォルダにドラッグして古いものを置き換えます。

アプリ内アップデートと Homebrew は共存できます。「起動時にアップデートを確認」（設定 → アップデート）がオンなら
MobAlt は自分で最新を保ち、`brew upgrade --cask mobalt` もいつでも安全に実行できます。アプリがすでに自分で
アップデート済みなら、Homebrew はそこにあるバージョンを再インストールするだけです。cask が `auto_updates` を
宣言しているため、cask 名を付けないただの `brew upgrade` は `--greedy` を付けない限り MobAlt を飛ばします。
Homebrew にアップデートさせたいときは cask 名を付けるか、`--greedy` を付けてください。

MobAlt の実行中にアップグレードしても問題ありません — MobAlt 自身のターミナルから実行しても大丈夫です。実行中の
アプリはメモリ上の古いバージョンを動かし続け、ディスク上の新しいバンドルに気付くと（1 分以内、またはウインドウが
再びフォーカスされたとき）タブの上にバナーを表示します：*MobAlt 0.11.0がディスクにあります — 実行中は0.10.1。
再起動で使えます。* **再起動**は、⌘Q と同じように開いている SSH/FTP 接続について先に確認し、ワークスペースを
保存して新しいバージョンを起動します。タブはワークスペースの復元で戻ってきます。**後で**は、さらに別の
バージョンが現れるまでバナーを隠します。アップデータの実行時に新しいバンドルがすでにディスクにあれば、
再ダウンロードはされません。確認は「0.11.0はすでにディスクにインストールされています。再起動すると使えます」と
報告し、同じ再起動を提案します。

## セッション

**セッション**パネルはブックマークのツリーです。`＋ セッション`（⌘N）でセッションを作成し、種類を選んで
「基本」タブを埋めます。セッションをダブルクリックすると接続、右クリックでコンテキストメニューが開きます
（開く、右/下に分割して開く、編集、複製、削除、トンネルを開始、このフォルダに新規セッション）。

![セッションエディタ](images/session-editor.png)

| 種類 | 内容 |
|---|---|
| SSH | SSH 経由のターミナル。SFTP ブラウザ、トンネル、X11 とエージェント転送付き |
| Mosh | `mosh` クライアントによるローミング対応ターミナル（SSH でブートストラップ） |
| Local | macOS のログインシェル（zsh/bash）。フォルダの追従付き |
| Telnet | NAWS/TTYPE ネゴシエーション付きの昔ながらの telnet |
| Serial | USB シリアルコンソール（ボーレート、フレーミング、フロー制御、ローカルエコー） |
| FTP | SFTP パネルでの FTP / FTPS（明示的 TLS）ファイルブラウザ |
| RDP / VNC | Windows App または macOS の画面共有に引き渡します |

**フォルダ**：パネルヘッダのフォルダボタン（新規フォルダ）でフォルダを作成します。セッションやフォルダはドラッグで
移動できます（ルートに戻すには空いている場所にドロップ）。フォルダのコンテキストメニューから、その中のすべての
セッションをグリッドまたはタブで開けます。

**アイコンとカラー**：エディタで絵文字とカラーを選びます。行、タブ、ペインヘッダに表示されるので、赤い「本番」
セッションを緑の「ステージング」セッションと取り違えにくくなります。

**読み込み / 書き出し**：パネル下部から `~/.ssh/config`（ホスト、ユーザ、ポート、鍵、ProxyJump）と MobaXterm の
`MobaXterm.ini`（ブックマーク）を読み込めます。ツリーのコンテキストメニューから、すべてのセッションを JSON として
書き出し / 読み込みできます。JSON ファイルにはすべてのセッションとフォルダが含まれますが、パスワードやパスフレーズは
決して含まれません。それらはこの Mac の MobAlt の暗号化ストアに残り、ファイルには保存済みという事実
（`hasPassword`）だけが記録されるので、別の Mac で読み込んだセッションは最初の接続時に尋ねてきます。読み込みは
手元のものにマージされます：`id` が既存のものと一致するセッションはファイル側のバージョンで置き換えられ
（ここで保存したパスワードは保持）、それ以外はすべて追加されます — `id` のない手書きの項目は常に追加され、
ファイルに書かれた `password` は取り込まれて暗号化保存されます — フォルダは追加され、何も削除されないので、
同じファイルを 2 回読み込んでも何も変わりません。名前がない、種類が不明、ポートが不正な項目はスキップされ、
トーストに件数が出ます。MobAlt のセッションファイルでないものは理由とともに拒否されます。`~/.ssh/config` は
すでにあるホスト（同じフォルダと名前）をスキップします。MobaXterm のブックマークは `MobaXterm` フォルダに入り、
以前に読み込んだもの（同じフォルダ、名前、ホスト）はその場で更新されます — ホスト、ポート、ユーザ、X11、圧縮は
`.ini` に従い、保存済みのパスワード、アイコン、カラー、トンネル、あなたが設定した鍵のパスはそのまま — なので
同じ `.ini` を 2 回読み込んでも、やはり何も変わりません。

**起動時コマンド**（「ターミナル」タブ）：1 行に 1 コマンドで、ターミナルの準備ができたらタイプされます。SSH なら
ログイン直後、ローカルシェルならプロンプトが出た直後です。例：*開始フォルダ*をプロジェクトに設定し、コマンドに
`claude --resume <id>` を書いたローカルセッション。ローカルセッションの*開始フォルダ*は、パスを直接入力するか
「選択…」ボタンで選びます。ボタンはフォルダダイアログを開き、キャンセルすると欄はそのままです。

## 接続

- **クイック接続**：ツールバーに `user@host[:port]` を入力して Enter を押します。プレフィックスで種類を選べます：
  `ssh://`、`mosh://`、`telnet://`、`ftp://`、`ftps://`、`rdp://`、`vnc://`。一致する保存済みセッションがあれば
  それが使われます。
- **認証**：*自動*は、設定された鍵、保存済みパスワード、SSH エージェント、`~/.ssh` のデフォルト鍵を順に試してから
  尋ねます。*パスワード*、*秘密鍵*、*SSHエージェント*を選ぶと方式を限定できます。パスフレーズ付きの鍵は一度だけ
  尋ねます。「セッションに保存」をオンにすると記憶します。
- **ホスト鍵**：初回接続でフィンガープリント（SHA256 と MD5）を表示します。受け入れると鍵が保存されます。鍵が
  変わった場合は目立つ形で警告され、黙って受け入れられることはありません。
- **SSH 鍵**：セッション → SSH鍵を生成…（ツールパネル、およびセッションエディタの秘密鍵欄の隣の「生成…」からも）
  が macOS の `ssh-keygen` を代わりに実行します：Ed25519（デフォルト）、RSA 4096 または ECDSA、コメント、
  強度ヒント付きの任意のパスフレーズ、保存先（デフォルトは `~/.ssh/id_<type>`、その名前が使用中なら番号付き。
  `~/.ssh` がなければ非公開の権限で作成され、ファイルは 0600 / 0644 になります）。生成後は公開鍵をコピーボタンと
  フィンガープリント付きで表示します。「ssh-agentに追加」は `ssh-add --apple-use-keychain` を実行し、
  「サーバにインストール…」は保存済みセッションに通常の認証で接続して `ssh-copy-id` のように公開鍵を
  `~/.ssh/authorized_keys` に追記します（二重には追記しません）。エディタからなら、*このセッションで使う*が
  鍵欄を埋めます。
- **アルゴリズム**：SSH詳細 → アルゴリズムに、このセッションが鍵交換、ホスト鍵、暗号、MAC について提示する
  内容が内蔵デフォルトで埋めた状態で並びます。リストを編集して絞り込みや並べ替えができ（不明な名前はその場で
  拒否されます）、*デフォルトに戻す*でリストが元に戻ります。「レガシーアルゴリズム（古い機器）」は、古い機器が
  今も必要とする SHA-1 鍵交換、CBC 暗号、DSA ホスト鍵を追加するプリセットです。保存されるのはデフォルトと異なる
  リストだけです。
- **踏み台ホスト**：SSH詳細 → 踏み台ホストで、別の保存済みセッションを踏み台（ProxyJump）として選びます。
- **失敗したとき**：ターミナルに何が起きたかが表示されます。たとえば
  `authentication failed — server accepts: publickey; tried: ~/.ssh/id_ed25519`（認証失敗）や、ポートで何も
  応答しなかったというヒントです。[トラブルシューティング](#トラブルシューティング)を参照してください。

## ターミナル

![分割グリッド](images/split-grid.png)

- **タブ**：セッションごとにタブが開きます。ドラッグで並べ替え、ダブルクリックで名称変更、中クリックで閉じます。
  ローカルタブのタイトルは現在のフォルダ名です。タブのコンテキストメニュー（右クリック、またはフォーカス中の
  タブで ⇧F10）から名称変更、複製、カラー、分割、閉じる操作ができます。*ほかを閉じる*、*左側のタブを閉じる*、
  *右側のタブを閉じる*、*すべて閉じる*は複数のタブを一度に閉じ、それらに含まれるアクティブな接続をまとめて
  数えた質問を 1 回だけします（「2件のアクティブな接続を含む3個のタブを閉じますか？」）。
- **タブの固定**（メニューの*タブを固定*、⇧⌘P）：固定したタブはタブバーの左端に、固定した順に移動し、状態の
  ドット、アイコン、短いタイトルだけに縮んで、✕ の位置に小さなピンが付きます。上記の一括クローズと中クリックは
  固定タブに触れません（⌘W、メニューの*閉じる*、フォーカス中のタブでの ⌫ は 1 つずつ閉じられます）。固定タブは
  固定されていないタブより右へはドラッグできません。固定はワークスペースの一部なので、再起動後も戻ります。
  *タブの固定を解除*は、固定ブロックの直後にタブを置きます。
- **タブを独立したウインドウに分離**（タブメニューの*新規ウインドウに移動*、⌥⌘N、またはセッションメニュー）：
  タブは 2 つ目の MobAlt ウインドウに移り、ターミナルはそのままです — 何も再接続せず、再起動もしません。新しい
  ウインドウは各ターミナルの最後の 256 KB の出力を描き直し、そこから続きます。分割タブはすべてのペインごと
  移動します。ウインドウには同じツールバー、メニュー、ショートカットがあり、サイドバーは折りたたまれた状態で
  始まります（そこで ⌘B を押すと表示）。MultiExec はウインドウごとです。2 つ目の分離ウインドウは最初のものから
  ずらして開くので、重なって隠れることはありません。分離したウインドウを閉じると、そのタブはセッションを動かした
  ままメインウインドウに戻ります — セッションが終了することはありません。最後のタブを閉じる（⌘W）と、戻すものが
  なくなるのでウインドウ自体が閉じます。メインウインドウを閉じると、分離ウインドウも含めて MobAlt が終了します。
  ワークスペースは分離ウインドウを記憶し、次回起動時に再び開いて、メインウインドウと同じようにセッションを
  再接続します。ウインドウ間でタブをドラッグすることはできません。ウインドウを閉じて戻すか、そこからもう一度
  分離してください。
- **分割とグリッド**：`分割 ▾`（⌘D で右、⇧⌘D で下）は空のペインを追加します。グリッドの項目は 1×2 … 2×4 の
  レイアウトを作ります（⌥⌘2/4/6/8）。ツリーのセッションを空のペインにドロップするとそこに接続し、ペインの端に
  ドロップするとその方向に分割、中央にドロップすると置き換えます。タブをペインにドラッグすると、そのターミナルを
  分割の中に移動します。⌥⌘1（表示 → 分割を解除、`分割 ▾` → 分割を解除）はタブの分割を解除します：デフォルトでは
  ほかの各ペインが、ターミナル、タイトル、状態をそのままに、ペインの順で現在のタブの直後に独立したタブとして
  置かれます — 何も再接続せず、出力も失われません。フォーカス中のペインがタブに残ります。設定 → ターミナル →
  **分割を解除**で代わりの動作を選べます：*アクティブなペインを残し、ほかを閉じる*（ほかのペインは閉じられ、
  アクティブな接続が切れる場合はいつもの確認が出ます）、または*毎回確認*（小さなダイアログが*ペインをタブに移動*、
  *このペインだけ残す*、または分割を保つキャンセルを提示します）。ペインが 1 つだけのタブには何もせず、ズーム中の
  ペインはまず元に戻されます。
- **ペインのズーム**（⇧⌘⏎、ペインヘッダの ⤢ ボタン、または `分割 ▾` → ペインをズーム）：フォーカス中のペインが
  tmux の zoom や iTerm2 の maximize のようにタブ全体に広がります。ほかのペインは接続されたまま隠れます。
  ペインヘッダに*ズーム中*のチップ、タブに小さな ⤢ が付きます。もう一度押す（またはヘッダの ⤡）とレイアウトが
  戻ります。分割、ペインを閉じる、グリッドレイアウト、隠れたペインへのフォーカス（⌘]）はまずレイアウトを
  戻します。各タブは再起動をまたいでも自分のズーム状態を保ちます。
- **MultiExec**（⇧⌘M）：オンの間、すべてのキー入力が画面に見えているすべてのターミナル — アクティブなタブの
  動作中のペイン、またはズーム中ならそのペインだけ — に送られます。ほかのタブには決して届かないので、操作したい
  サーバはタブを分割（またはグリッドを使用）して並べてください。バナーには受信中の表示ターミナルの数が出て、
  切り替えたタブに追従します。
- **リモート監視バー**：各 SSH ペインはヘッダの下に 1 行のバーを表示します — CPU、メモリ使用量 / 合計、ルート
  ディスクの使用量、ネットワークの ↓ / ↑ レート、ロードアベレージ、稼働時間、ホスト名 — 3 秒ごとに更新
  （設定 → 機能 → 監視、2–30 秒）。小さな POSIX `sh` スニペットがセッション自身の接続で実行されるので、2 回目の
  ログインは不要で、踏み台ホスト越しでも動き、ターミナルには何も出力しません。Linux ホストは `/proc` から、
  macOS と BSD は `sysctl`、`vm_stat`、`netstat` から読み取ります。実行できないホスト（`sh` がない、アクセス拒否）
  は薄い色で*監視は利用できません*と表示し、再接続するまで再度問い合わせません。ペインが画面に出ていない間
  （別のタブが前面、兄弟ペインがズーム中、ウインドウが非表示）はポーリングを止め、戻ると再開します。セッション
  ごと（SSH詳細 → *リモート監視バーを表示*）、ペインごと（ペインヘッダのパルスボタン、表示 → リモート監視バー、
  またはターミナルのコンテキストメニュー）、あるいは設定で全セッション一括でオフにできます。Mosh ペインには
  自身の SSH チャネルがないため、SFTP 補助接続が開いている間だけ、その接続経由でバーを表示します。
- **検索**（⌘F）：大文字小文字と正規表現の切り替え、一致数カウンタ付きのインクリメンタル検索。
- **キーワードのハイライト**：エラー、警告、OK/done、IP アドレス、URL、サイズ（`512M`、`3.2GB`）が到着と同時に
  色付けされます。カラーはターミナルのテーマから取るので、どのパレットでも読めます。設定 → 機能 →
  *キーワードのハイライト*でオフにできます。「ルール…」で表が開きます — 各ルールはプレーンテキストまたは正規表現、
  大文字小文字を区別しない、カラー、任意の背景、太字と下線で構成されます。*デフォルトを復元*で内蔵セットに
  戻ります。ルールが重なる場合は先に一致したもの、次に長いものが優先されます。セッションの「ターミナル」タブで
  強制的にオン/オフにできます（*キーワードのハイライト：デフォルト / オン / オフ*）。新しく書かれた行だけが
  走査され（vim のような全画面アプリには触れません）、装飾が残るのはターミナルあたり最大 2,000 件 — 長い出力では
  古い行から順にプレーンに戻ります — ⌘K ですべて消えます。
- **Zmodem（rz/sz）**：ターミナルそのものを通してファイルを動かします。シリアルコンソールや、SFTP が使えない
  踏み台ホスト越しの昔ながらの方法です。リモートで `sz file …` を実行すると Mac にダウンロード、`rz` で Mac から
  アップロードします。MobAlt はストリーム内の転送を検出してターミナルを一時停止し、SFTP パネルの転送リスト
  （キャンセル付き）とステータスバーのカウンタに表示します。ダウンロード先はダウンロードフォルダ（設定 → 一般）、
  未設定ならその場で選ぶフォルダです。アップロードはファイル選択ダイアログを開きます。SSH、ローカル、telnet、
  シリアルのペインで動作します — Mosh は除きます（そのストリームは mosh クライアントのもので、生のバイト
  ストリームではありません）。設定 → 機能 → 転送 → 「Zmodem転送（rz/sz）」でオフにできます（デフォルトはオン）。
  オフにすると `rz`/`sz` のバイト列は以前と同じようにただの文字化けとして表示されます。ペインでの Ctrl-C または
  リストのキャンセルで転送が終わります：リモートの `sz`/`rz` に停止が伝えられ、まだ送信中だったものは描画されずに
  捨てられ、1 秒以内にプロンプトが戻ります。リモートの `sz` が死んだ場合は数秒以内に検知されます。同名の 2 回目の
  ダウンロードは `name (1).ext` として保存され、その名前でリストに出ます。
- **クリップボード**：選択するとコピーされます（設定 → ターミナル → 選択時にコピー）。右クリックでペースト
  （⇧右クリックでメニュー）。Finder から SSH ターミナルにファイルをドロップするとアップロード、ローカルターミナルに
  ドロップするとパスがペーストされます。
- **ペーストガード**：複数行（または 1000 文字超）のペーストは先に確認します — 「{n}行を…にペーストしますか？」が
  編集可能なプレビューでテキストを表示し、⌘⏎ でペースト、Esc でキャンセルです。すべてのペーストは、クリップ
  ボードには見えないものについても検査されます：ゼロ幅文字や双方向文字、ノーブレークスペース（目にはスペース、
  シェルには単語の一部）、制御文字、末尾の改行（最後の行がすぐ実行される）、行の途中の復帰文字、`curl … | sh`、
  `~/.zshrc` の仲間や `~/.ssh/authorized_keys` への書き込み、`rm -rf /` 系のコマンド、キリル文字やギリシャ文字の
  紛らわしい文字が混ざったラテン文字の単語。見つかったものは一覧になり、プレビューにマークされます。*クリーンに
  してペースト*は隠れた文字と末尾の改行を取り除き、*そのままペースト*はテキストを変えずに送ります。どちらの検査も
  設定 → 機能 → ペーストガードのスイッチです（デフォルトはオン）。対象は ⌘V、右クリック、ペインへのテキストの
  ドロップで、マクロは含みません。MultiExec がオンのときは 1 回の確認が表示中のすべてのターミナルに適用されます。
- **キー**：Shift+Enter と Option+Enter は ESC+CR を送ります（Claude Code などの TUI アプリでの改行）。Option は
  デフォルトで Meta として働きます。
- **ログ**：ターミナル → セッションログを開始/停止、またはセッションのオプションで、生の出力を
  `~/Documents/MobAlt Logs/` に書き込みます。設定 → ログ → *セッションログからカラーと制御シーケンスを取り除く*を
  オンにすると、代わりにプレーンテキストで保存します（ANSI カラー、カーソル移動、フォルダ追跡用フックが
  取り除かれます）。
- **テーマと外観**：設定 → ターミナル → テーマは、ターミナルだけでなくプログラム全体に色を付けます。ツールバー、
  サイドバー、タブ、ステータスバー、ダイアログ、メニュー、トースト、バナーは、選んだテーマから導いたクローム
  パレットになります — *Moba Dark* はおなじみのダークなクローム、*Light* はほぼ白のパネルと暗い文字の明るい
  アプリ、*One Dark*、*Dracula*、*Solarized Dark*、*Gruvbox Dark* はそれぞれの色味でクロームを染めます — ネイティブ
  コントロールとタイトルバーも追従します。クロームのすべての文字色は、どのテーマでも背景に対して 4.5:1 以上の
  コントラストを保ちます。テーマの選択欄にはそのパレットの色でサンプルプロンプトが表示され、保存するとすぐに
  適用されます。設定 → ターミナル → フォントはすべてのターミナルに適用されます。セッションは「ターミナル」タブで
  テーマとフォントを上書きでき、その場合そのペインのターミナルだけが色を変え、ウインドウはグローバルなテーマの
  ままです。

## ファイル（SFTP / FTP）

![SFTP パネル](images/sftp-panel.png)

**SFTP** パネルはアクティブな SSH または FTP ペインに追従します。接続時に自動的に開きます
（設定 → 一般 → 「SSH接続時にSFTPパネルに切り替える」）。

- フォルダのダブルクリック、パスの入力（`~` も使えます）、⬆ / 🏠 / ⟳ で移動します。「ターミナルに追従」は
  パネルをシェルの現在のディレクトリに合わせます（セッションのオプションが必要で、小さなプロンプトフックを
  挿入します）。`>_` はターミナルに `cd` を送ります。
- ツールバーとコンテキストメニュー：新規フォルダ、名称変更、アクセス権、削除、ダウンロード、アップロード。
  ⌘ / ⇧ で複数選択できます。Finder からリストにファイルをドラッグするとアップロードします。同名のものがあれば
  上書き前に確認します。
- テキストファイルをダブルクリックすると内蔵エディタで編集できます（⌘S で書き戻し）。「外部エディタで編集」は
  お使いのエディタ（設定 → 一般 → 外部エディタ）で開き、保存のたびに再アップロードします。
- 転送には進行状況、速度、キャンセルボタンが表示され、ダウンロード後は「Finderに表示」が使えます。
- 列ヘッダで名前、サイズ、日付で並べ替えられます。サイドバーが狭いときは日付列が隠れます。

## トンネル（ポート転送）

![トンネル](images/tunnels.png)

`トンネル`（⇧⌘U）で SSH ポート転送を管理します：

- **ローカル（-L）**：SSH ホスト経由で `127.0.0.1:8080 → db.internal:5432`。
- **リモート（-R）**：サーバ上のポートをローカルのサービスに転送して戻します。
- **ダイナミック（-D）**：サーバ経由のローカル SOCKS5 プロキシ。

開いている接続の上でトンネルを開始するか、MobAlt に保存済みセッションへの専用接続を開かせます。セッションの
**トンネル**タブに並べたトンネルは、そのセッションの接続時に自動的に開始され、バインドに失敗すれば通知されます。

## X11、Mosh、シリアル、RDP/VNC

- **X11**：SSH詳細で「X11転送（XQuartz）」をオンにします。MobAlt は必要に応じて XQuartz を起動し、ディスプレイを
  転送して認証クッキーを差し替えるので、`xeyes` や `gedit` がそのまま動きます。ステータスバーに X11 の利用可否が
  表示されます。
- **Mosh**：ローカルに `brew install mosh`、ホストに `mosh-server`（UDP 60000-61000）が必要です。ペインは mosh
  クライアントを実行し、SSH ブートストラップには鍵、エージェント、または対話的プロンプトが使われます。リモートの
  PATH に `mosh-server` がなければパスを設定してください。
- **Mosh + SFTP**：mosh には SFTP チャネルがないため、SFTP パネルは同じホストへのシェルなしの別 SSH 接続
  （同じ鍵、エージェント、プロンプト）で Mosh ホストを閲覧します。セッションで「SFTPブラウザを自動的に開く」が
  オン（かつ設定 → 一般 →「SSH接続時にSFTPパネルに切り替える」もオン）なら自動的に開き、そうでなければパネルの
  「このホストのSFTPを開く（SSH経由）」ボタン、またはペインメニューの「SFTPブラウザを開く」から開きます。
  ペインと一緒に閉じられます。
- **シリアル**：エディタが USB シリアルデバイスを一覧します。ボーレート、データ/ストップビット、パリティ、
  フロー制御、ローカルエコー、Enter の送信内容（CR、LF、CRLF）を設定します。
- **RDP / VNC**：MobAlt は `.rdp` ファイルを書いて Windows App を開くか、`vnc://` を画面共有で開きます。
  セッションはほかのブックマークと同じようにホスト、ユーザ、フォルダを保持します。

## ツールとマクロ

- **ツール**パネル：ping、traceroute、DNS ルックアップ、ポートスキャン、ローカルネットワーク情報。長い実行には
  停止ボタンがあります。
- **Wake-on-LAN**（ツールパネル）：MAC アドレスを任意の書き方（`aa:bb:cc:dd:ee:ff`、`aa-bb-…`、`aabb.ccdd.eeff`、
  区切りなしの 16 進数）で入力して「起動」を押します。マジックパケットが UDP ブロードキャストとして 3 回送られます
  （デフォルトは 255.255.255.255 のポート 9。192.168.1.255 のようなダイレクトブロードキャストなら別のサブネットに
  届きます）。直近 10 件のアドレスが任意のラベル付きで記憶され、入力中に候補として出ます。
- **ネットワークスキャナ**（ツールパネル）：CIDR（`192.168.1.0/24`）、範囲（`10.0.0.1-10.0.0.50` または
  `10.0.0.1-50`）、または 1 台のホストを /16 まで、ICMP ping と短いポートリスト（デフォルトは 22、80、443、3389、
  5900）への TCP 接続でスキャンします。並列数とタイムアウトを調整でき、応答したホストすべての逆引き DNS も
  行えます。応答したホストは見つかり次第、並べ替え可能な表（IP、ホスト名、往復時間、開いているポート）に
  現れ、進行状況バーが `123/254` と数えます。「停止」でキャンセル、＋ はそのホストへの SSH を埋めた状態で
  セッションエディタを開き、「テキストとしてコピー」は表をクリップボードに載せます。
- **マクロ**パネル：ターミナルのキー入力を記録し（● 記録 / ■ 停止）、名前を付けて保存して、アクティブな
  ターミナルまたはすべてのターミナルで再生します。テキストマクロは直接入力でき、`\n` や `\x1b[A` のような
  エスケープシーケンスに対応しています。

## ワークスペースと設定

MobAlt は次回起動時にタブ、分割、セッションを復元し（独立したウインドウに分離したタブはウインドウとして
戻ります）、SSH セッションを再接続します（ローカルシェルは最後のフォルダで開き直します）。設定 → 一般 → 動作で
オフにできます。

![設定](images/settings.png)

設定には 5 つのタブがあり、どれも最小のウインドウにスクロールなしで収まります：**一般**（インターフェイスの言語、
終了の確認、SFTP パネルへの切り替え、ワークスペースの復元、ローカルシェルとそのフォルダ連携、外部エディタ、
ダウンロードフォルダ、SSH キープアライブ、そしてすべての保存場所を示す「設定フォルダを開く」）、**ターミナル**
（フォント、行の高さ、カーソル、スクロールバック、テーマ — ウインドウ全体の見た目、*テーマと外観*を参照 —
マウス/キー、および*分割を解除*が分割タブのほかのペインをどうするか：独立したタブに移動、閉じる、毎回確認）、
**機能**（ペーストガード、リモート監視バーとその更新間隔、キーワードのハイライトとそのルール表、Zmodem 転送）、
**ログ**（ログフォルダ、プレーンテキストのセッションログ）、**アップデート**（起動時の確認と「今すぐ確認」）。

### インターフェイスの言語

MobAlt のメニュー、ツールバー、パネル、ダイアログ、メッセージは 10 の言語で使えます：English、한국어、简体中文、
日本語、Tiếng Việt、हिन्दी、Deutsch、Français、Español、Português。デフォルト（**システムのデフォルト**）では
macOS の言語リスト（システム設定 → 一般 → 言語と地域）に従います：そのリストで MobAlt が対応する最初の言語が
使われ、どれも該当しなければ英語です。設定 → 一般 → **言語**で明示的に選べます。変更はすべてのウインドウに
すぐ反映され — 何も再起動せず、接続もそのまま — 記憶されます。ターミナルの出力は決して翻訳されません：
リモートホストが出力したものはそのまま表示されます。ユーザガイドも同じ 10 言語で用意されています
（`docs/USER_GUIDE.<language>.md`）。ヘルプ → **ユーザガイド**は現在の言語のものを開きます。

設定を変えずに一度だけ別の言語で MobAlt を実行するには（スクリーンショット、テスト）、環境変数
`MOBALT_LANG=<code>` を付けて起動します（`en`、`ko`、`zh-CN`、`ja`、`vi`、`hi`、`de`、`fr`、`es`、`pt`）。

## データとプライバシー

すべては `~/Library/Application Support/MobAlt/` に置かれます：`sessions.json`（パスワードとパスフレーズは
macOS のキーチェーンで暗号化）、`settings.json`、`known_hosts`、`workspace.json`、zsh 連携ファイル。
セッションログは `~/Documents/MobAlt Logs/` に書かれます。MobAlt が接続するのはあなたが設定したホストだけで、
任意のアップデート確認は GitHub のリリース一覧を読むだけです。詳細：[SECURITY.md](../SECURITY.md)。

## トラブルシューティング

- **「Timed out while waiting for handshake」 / ETIMEDOUT**：そのポートで何も応答しませんでした。アドレス、VPN、
  ルーターの転送設定を確認し、ローカルターミナルで `nc -vz host port` を試してください。
- **「authentication failed — server accepts: …; tried: …」**：サーバが MobAlt の提示したものを受け付けません
  でした。「accepts」のリストをセッションの認証方式と比べてください。鍵のみのサーバなら正しい鍵ファイルを
  選びます。失敗を繰り返すと、fail2ban や sshd の送信元ごとのペナルティによって IP がしばらくブロックされる
  ことがあります。
- **「no matching key exchange / host key / cipher / MAC: this session offers …; the server offers …」**：両側に
  共通のアルゴリズムがありません。メッセージにサーバが話せるものが列挙されるので、そのうちの 1 つを SSH詳細 →
  アルゴリズムに追加します（または*デフォルトに戻す*）。SHA-1 / CBC しか提示しない古い機器なら
  「レガシーアルゴリズム（古い機器）」をオンにしてください。
- **ホスト鍵が変わった**：サーバが再インストールされたか、何かが接続を横取りしています。理由が分かっている場合
  だけ受け入れてください。古い鍵は設定フォルダの `known_hosts` から削除できます。
- **X11 アプリが表示されない**：XQuartz をインストールし、リモートのシェルが起動ファイルで `DISPLAY` を
  上書きしていないことを確認してください。
- **Mosh**：「mosh client not found」はローカルに `brew install mosh` がないということです。「mosh-server not
  found」はホストにないか、その PATH に入っていないということです（セッションでパスを設定してください）。
- **自分でビルドしたアプリへの Gatekeeper の警告**：右クリック → 開く を一度行うか、
  `xattr -dr com.apple.quarantine /Applications/MobAlt.app` を実行します。
- **`brew upgrade --cask mobalt` で `hdiutil: attach failed – Resource busy`**：別の Homebrew プロセス
  （たとえば `brew audit` や `brew fetch`）がその瞬間に同じ DMG をマウントしていました。コマンドをもう一度
  実行してください。
