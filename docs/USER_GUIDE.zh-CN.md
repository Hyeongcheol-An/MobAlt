# MobAlt 用户指南

本指南的其他语言版本：[English](USER_GUIDE.md) · [한국어](USER_GUIDE.ko.md) · [简体中文](USER_GUIDE.zh-CN.md) · [日本語](USER_GUIDE.ja.md) · [Tiếng Việt](USER_GUIDE.vi.md) · [हिन्दी](USER_GUIDE.hi.md) · [Deutsch](USER_GUIDE.de.md) · [Français](USER_GUIDE.fr.md) · [Español](USER_GUIDE.es.md) · [Português](USER_GUIDE.pt.md) · [العربية](USER_GUIDE.ar.md)

MobAlt 是一款 MobaXterm 风格的 macOS 工作台：左侧是会话树，中间是可分标签页、可拆分的终端，
侧边面板中则有 SFTP 浏览器、网络工具和宏。

另请参阅：[MobaXterm 26.6 功能对照](MOBAXTERM_PARITY.md)（英文）——MobAlt 具备什么、缺少什么、有哪些不同做法，以及路线图。

## 安装

- **Homebrew**：`brew tap Hyeongcheol-An/tap && brew trust Hyeongcheol-An/tap && brew install --cask mobalt`
  （Homebrew 7 会要求你对第三方 tap 授予一次信任；之后用 `brew upgrade --cask mobalt` 更新）
- **DMG**：从 [Releases](https://github.com/Hyeongcheol-An/MobAlt/releases) 下载 Apple 芯片（`arm64`）或
  Intel（`x64`）版 DMG，将 MobAlt 拖到“应用程序”文件夹。

发布版本均已签名并经过公证。系统要求：macOS 13 或更高版本。可选的辅助软件：
X11 转发需要 [XQuartz](https://www.xquartz.org/)，Mosh 会话需要 `brew install mosh`，
RDP 需要 Windows App。

MobAlt 启动时会在 GitHub Releases 上检查是否有新版本，并在对话框中提示；未经你确认，
不会下载或安装任何内容。请参阅[更新](#更新)。

## 更新

有三种方式可以升级到新版本，最终都会把新的应用包放到 `/Applications/MobAlt.app`：

- **应用内更新**：MobAlt 启动时检查 GitHub Releases（可在“设置”→“更新”中关闭）；
  “帮助”→“检查更新…”或“设置”→“更新”中的“立即检查”可手动检查。有新版本时会在对话框中提示，
  只有在你同意后才会下载，并在退出时安装；选择“立即重新启动”则立即安装。
- **Homebrew**：`brew upgrade --cask mobalt` 会替换“应用程序”文件夹中的应用。
- **DMG**：从 [Releases](https://github.com/Hyeongcheol-An/MobAlt/releases) 下载新的 DMG，
  将 MobAlt 拖到“应用程序”文件夹并替换旧版本。

应用内更新与 Homebrew 可以并存。开启“启动时检查更新”（“设置”→“更新”）后，MobAlt 会自动保持最新；
同时运行 `brew upgrade --cask mobalt` 也始终是安全的：如果应用已自行更新，Homebrew 只会重新安装已经存在的版本。
由于该 cask 声明了 `auto_updates`，普通的 `brew upgrade`（不指定 cask）会跳过 MobAlt，除非加上 `--greedy`；
如果想让 Homebrew 负责更新，请指定 cask 名称或加上 `--greedy`。

MobAlt 运行期间升级没有问题——即使是在 MobAlt 自己的终端里升级。正在运行的应用会继续从内存中执行旧版本，
并在发现磁盘上的新应用包后（一分钟内，或窗口重新获得焦点时）在标签栏上方显示横幅：
*磁盘上已安装 MobAlt 0.11.0——当前运行的是 0.10.1。重新启动即可使用。*
**重新启动**会先就打开的 SSH/FTP 连接进行询问（与 ⌘Q 相同），存储工作区并启动新版本；
你的标签页会通过工作区恢复回来。**稍后**会隐藏横幅，直到再出现更新的版本。
如果更新程序运行时新应用包已在磁盘上，则不会重复下载：检查结果会显示
“MobAlt 0.11.0 已安装在磁盘上；重新启动即可使用”，并提供同样的重新启动选项。

## 会话

**会话**面板就是你的书签树。用 `＋ 会话`（⌘N）创建会话，选择类型并填写“基本”标签页。
连按会话即可连接；右键点击打开上下文菜单（打开、向右/向下拆分、编辑、复制、删除、启动隧道、
在此文件夹中新建会话）。

![会话编辑器](images/session-editor.png)

| 类型 | 作用 |
|---|---|
| SSH | 通过 SSH 的终端，附带 SFTP 浏览器、隧道、X11 和代理转发 |
| Mosh | 通过 `mosh` 客户端的漫游终端（经 SSH 引导） |
| 本地 | 你的 macOS 登录 Shell（zsh/bash），支持文件夹跟随 |
| Telnet | 经典 telnet，支持 NAWS/TTYPE 协商 |
| 串口 | USB 串口控制台（波特率、帧格式、流控制、本地回显） |
| FTP | SFTP 面板中的 FTP / FTPS（显式 TLS）文件浏览器 |
| RDP / VNC | 交给 Windows App 或 macOS“屏幕共享”处理 |

**文件夹**：面板标题栏中的文件夹按钮（“新建文件夹”）可创建文件夹；拖动会话和文件夹即可移动它们
（放到空白区域即移到顶层）。文件夹的上下文菜单可以将其中的所有会话以网格或标签页方式打开。

**图标和颜色**：在编辑器中选择一个表情符号和一种颜色。它们会显示在会话行、标签页和窗格标题栏上，
这样红色的“生产环境”会话就不容易与绿色的“测试环境”会话混淆。

**导入/导出**：面板底部可以导入 `~/.ssh/config`（主机、用户、端口、密钥、ProxyJump）和
MobaXterm 的 `MobaXterm.ini`（书签）。在会话树的上下文菜单中可以将所有会话导出/导入为 JSON。
JSON 文件包含每个会话和文件夹，但绝不包含密码或密码短语：它们留在此 Mac 上 MobAlt 的加密存储中，
文件只记录是否存储过密码（`hasPassword`），因此在另一台 Mac 上导入的会话会在首次连接时询问。
导入会与现有内容合并：`id` 与现有会话相同的会话会被文件中的版本替换（此处为它存储的密码会保留），
其他会话一律添加——手写的、没有 `id` 的条目总是会被添加，文件中写入的 `password` 会被读取并加密存储——
文件夹只会添加，不会删除任何内容，因此同一文件导入两次不会产生变化。没有名称、类型未知或端口无效的条目会被跳过，
并在提示消息中计数；不是 MobAlt 会话文件的文件会被拒绝并说明原因。`~/.ssh/config`
会跳过已有的主机（相同文件夹和名称）。MobaXterm 书签放在 `MobaXterm` 文件夹下；之前导入过的书签
（相同文件夹、名称和主机）会就地刷新——主机、端口、用户、X11 和压缩以 `.ini` 为准，
而已存储的密码、图标、颜色、隧道和你设置的密钥路径保持不变——因此同一个 `.ini` 导入两次同样不会产生变化。

**启动命令**（“终端”标签页）：每行一条命令，在终端就绪后输入。SSH 会话在登录后立即输入；
本地 Shell 在提示符出现后立即输入。示例：一个本地会话，*起始文件夹*设为某个项目，
命令为 `claude --resume <id>`。
本地会话的*起始文件夹*可以完整输入路径，也可以用其“浏览…”按钮选择；该按钮会打开文件夹对话框，
取消时字段保持原样。

## 连接

- **快速连接**：在工具栏中输入 `user@host[:port]` 并按 Enter。前缀决定类型：
  `ssh://`、`mosh://`、`telnet://`、`ftp://`、`ftps://`、`rdp://`、`vnc://`。如果有匹配的已存储会话，
  则使用该会话。
- **身份验证**：*自动*会在提示输入之前依次尝试已配置的密钥、已存储的密码、SSH 代理以及
  `~/.ssh` 中的默认密钥。选择*密码*、*私钥*或 *SSH 代理*可限定方式。带密码短语的密钥只询问一次；
  勾选“存储到会话”即可保留。
- **主机密钥**：首次连接时会显示指纹（SHA256 和 MD5）。接受后会存储该密钥；
  密钥发生变化时会醒目地标示出来，绝不会悄悄接受。
- **SSH 密钥**：“会话”→“生成 SSH 密钥…”（工具面板中也有，会话编辑器私钥字段旁边还有*生成…*）
  会为你运行 macOS 的 `ssh-keygen`：Ed25519（默认）、RSA 4096 或 ECDSA，一条注释，
  可选的密码短语（带强度提示），以及文件（默认为 `~/.ssh/id_<type>`，如该名称已被占用则加编号；
  `~/.ssh` 不存在时会以私有权限创建，文件权限为 0600 / 0644）。生成后会显示带“拷贝”按钮的公钥及其指纹。
  “添加到 ssh-agent”会运行 `ssh-add --apple-use-keychain`；“安装到服务器…”会以惯用的身份验证方式
  连接到一个已存储的会话，并像 `ssh-copy-id` 一样将公钥追加到其 `~/.ssh/authorized_keys`（绝不重复添加）。
  从编辑器打开时，*在此会话中使用*会填入密钥字段。
- **算法**：“SSH 高级”→“算法”列出会话在密钥交换、主机密钥、加密算法和 MAC 算法方面提供的选项，
  预先填入内置默认值；编辑列表即可限制或重新排序（未知的名称会被当场拒绝），
  *重置为默认值*会还原列表，“旧版算法（旧设备）”是一个预设，会加入老旧设备仍需要的
  SHA-1 密钥交换、CBC 加密算法和 DSA 主机密钥。只有与默认值不同的列表才会被存储。
- **跳板机**：“SSH 高级”→“跳板机”可选择另一个已存储的会话作为堡垒机（ProxyJump）。
- **连接失败时**：终端会打印发生了什么，例如
  `身份验证失败——服务器接受：publickey；已尝试：~/.ssh/id_ed25519`，
  或提示该端口没有任何响应。请参阅[故障排除](#故障排除)。

## 终端

![拆分网格](images/split-grid.png)

- **标签页**：每个会话都会打开一个标签页。拖动标签页可调整顺序，连按可重新命名，中键点击可关闭。
  本地标签页以其当前文件夹命名。标签页的上下文菜单（右键点击，或在聚焦的标签页上按 ⇧F10）
  可以重新命名、复制、设置颜色、拆分和关闭：*关闭其他标签页*、*关闭左侧标签页*、*关闭右侧标签页*和
  *全部关闭*可一次关闭多个标签页，并只询问一次，同时统计其中所有活动连接
  （“要关闭 3 个标签页（含 2 个活动连接）吗？”）。
- **固定的标签页**（菜单中的*固定标签页*，⇧⌘P）：固定的标签页会按固定顺序移到标签栏左侧，
  并缩小为状态圆点、图标和简短标题，原来 ✕ 的位置换成一个小图钉。上述批量关闭和中键点击
  不会影响固定的标签页（⌘W、菜单中的*关闭*以及在聚焦的标签页上按 ⌫ 仍可关闭单个标签页），
  固定的标签页也不能拖到未固定的标签页之后。固定状态属于工作区的一部分，因此重新启动后会恢复。
  *取消固定标签页*会把该标签页放到固定区之后。
- **将标签页分离到独立窗口**（标签页菜单中的*分离到新窗口*、⌥⌘N 或“会话”菜单）：
  标签页会移到第二个 MobAlt 窗口中并保留其终端——不会重新连接，也不会重新启动。
  新窗口会重绘每个终端最后 256 KB 的输出并从那里继续；拆分的标签页会连同所有窗格一起移动。
  该窗口拥有相同的工具栏、菜单和快捷键，启动时边栏处于折叠状态（按 ⌘B 显示）；MultiExec 按窗口独立。
  第二个分离的窗口会相对第一个错开打开，彼此不会遮挡。关闭分离的窗口时，其标签页会连同仍在运行的会话
  交还给主窗口——它绝不会结束会话；关闭其最后一个标签页（⌘W）则会关闭窗口本身，因为已没有可交还的内容；
  关闭主窗口会退出 MobAlt，包括所有分离的窗口。工作区会记住分离的窗口，并在下次启动时重新打开它们，
  像主窗口一样重新连接其中的会话。标签页不能在窗口之间拖动：关闭窗口即可把它们带回来，
  或从那里再次分离。
- **拆分和网格**：`拆分 ▾`（⌘D 向右，⇧⌘D 向下）会添加一个空窗格；网格项可生成
  1×2 … 2×4 布局（⌥⌘2/4/6/8）。将会话从会话树拖到空窗格上即可在那里连接，拖到窗格边缘可向该方向拆分，
  拖到窗格中央则替换它。将标签页拖到窗格上可把该终端移入拆分布局。⌥⌘1（“显示”→“取消拆分”，
  `拆分 ▾`→“取消拆分”）会取消拆分标签页：默认情况下，其他每个窗格都会变成独立的标签页，按窗格顺序
  紧随当前标签页之后，其终端、标题和状态保持原样——不会重新连接，也不会丢失输出；聚焦的窗格保留原标签页。
  “设置”→“终端”→**取消拆分**可选择其他处理方式：*保留当前窗格，关闭其他窗格*（其他窗格会关闭，
  如有活动连接会被断开，则照常询问）或*每次询问*（一个小对话框提供*将窗格移为标签页*、*只保留此窗格*或
  “取消”，后者保留拆分状态）。只有一个窗格的标签页不受影响，已放大的窗格会先被恢复。
- **放大窗格**（⇧⌘⏎、窗格标题栏中的 ⤢ 按钮，或 `拆分 ▾`→“放大窗格”）：聚焦的窗格会填满标签页，
  类似 tmux 的 zoom 或 iTerm2 的最大化。其他窗格保持连接但被隐藏；窗格标题栏显示*已放大*标记，
  标签页上显示一个小 ⤢。再按一次（或点按标题栏中的 ⤡）即可恢复布局。拆分、关闭窗格、应用网格布局
  或聚焦隐藏的窗格（⌘]）都会先恢复布局。每个标签页各自保留放大状态，重新启动后也是如此。
- **窗格菜单**（右键点击终端；开启*右键点击粘贴*时，按住 ⇧ 或 ⌃ 再右键点击）：除了拷贝、粘贴、查找、清除、
  拆分和放大之外，还包含 MobaXterm 终端菜单中针对单个终端的项目。*重新命名窗格…*（MobaXterm 的
  *Rename Terminal*）为窗格本身命名：窗格标题栏显示该名称，当窗格为标签页命名时标签页也采用该名称，
  Shell 自己的标题序列不再更改它；名称留空则恢复为自动标题。*窗格设置…*相当于 MobaXterm 的“重新配置当前终端”：
  为此窗格设置主题、字体和字号、光标样式和闪烁、回滚行数、关键词高亮、监控栏（SSH / Mosh）、只读和背景标签，
  覆盖会话和“设置”中的值（留空的字段沿用这些值）。*应用到此窗格*只更改此窗格——这些值会随窗格一起经过放大、
  分离和工作区保存——而*存储到会话*（仅限已存储的会话）还会写入会话本身拥有的字段（主题、字号、关键词高亮、
  监控、背景标签），之后从该会话打开的每个窗格都会沿用。*字号 ▸*逐级调整此窗格的字号（⌘= / ⌘- / ⌘0
  对聚焦的窗格作用相同；*实际大小*恢复为窗格自身的字号）。*只读*会丢弃发往该窗格的按键和粘贴内容，而其输出照常显示——
  标题栏中的*只读*标记会提示这一点，MultiExec 也会跳过该窗格。
- **背景标签**：绘制在窗格文字背后的大号淡色名称——默认为会话名称——便于一眼认出服务器，类似 iTerm2 的 badge
  （MobaXterm 只在标签栏上为窗格命名）。窗格菜单中的*背景标签 ▸*可以显示或隐藏它、设置其文本（*设置文本…*；
  留空则使用会话的标签，否则使用会话名称或窗格标题），并将其放在*居中*或*右上角*；会话编辑器的“终端”标签页
  （*背景标签*：显示、文本、位置）可为会话的每个窗格开启它，窗格自己的设置优先于会话的设置。
  标签随窗格缩放，在很小的窗格中隐藏，采用窗格的前景色并以 16% 的不透明度显示，
  且绝不会成为终端缓冲区、选择内容、拷贝内容或会话日志的一部分。
- **MultiExec**（⇧⌘M）：开启时，每次按键都会发送到屏幕上所有可见的终端——当前标签页中的活动窗格，
  或在某个窗格填满标签页时只发送到该已放大的窗格。其他标签页永远不会收到，因此请拆分标签页（或使用网格），
  把要同时操作的服务器并排放置。横幅会显示有多少个可见终端在接收输入，并跟随你切换到的标签页。
  要排除某个窗格，请勾选其终端下方的复选框——*将“名称”排除在 MultiExec 模式之外*，与 MobaXterm 相同——
  或使用窗格右键菜单中的*排除在 MultiExec 之外*：该窗格仍留在屏幕上并保持连接，在其他地方输入的按键不再发送到它，
  而在它里面输入的内容只发送给它自己（便于在不退出该模式的情况下只在一台服务器上运行一条命令）。
  此时横幅会追加*、已排除 N 个*，或提示所有可见终端均已排除。在复选框所在的信息条或横幅上右键点击
  （在聚焦的复选框上按 ⇧F10）会打开该模式的菜单：*全部激活*、*全部取消激活*、*反向选择*和
  *同步鼠标滚轮滚动*——后者会在你用滚轮滚动一个终端时，让其他正在接收输入的终端滚动相同的行数。
  每次关闭 MultiExec 时这些复选框都会被清除；它们不会被保存。
- **远程监控栏**：每个 SSH 窗格的标题栏下方都会显示一行信息条——CPU、内存已用/总量、根磁盘已用空间、
  网络 ↓ / ↑ 速率、平均负载、运行时间和主机名——每 3 秒刷新一次（“设置”→“功能”→“监控”，2–30 秒）。
  一小段 POSIX `sh` 脚本通过会话自身的连接运行，因此无需再次登录，可穿过跳板机，也绝不会向终端打印内容；
  Linux 主机从 `/proc` 读取，macOS 和 BSD 则通过 `sysctl`、`vm_stat` 和 `netstat` 读取。
  无法运行该脚本的主机（没有 `sh`、权限被拒绝）会显示暗色的*监控不可用*，在重新连接之前不会再次查询。
  窗格不在屏幕上时（前面有其他标签页、同一标签页中有已放大的窗格、窗口被隐藏）轮询会暂停，
  重新显示时恢复。可按会话（“SSH 高级”→*显示远程监控栏*）、按窗格（窗格标题栏中的脉搏按钮、
  “显示”→“远程监控栏”，或终端的上下文菜单）或在“设置”中为所有会话关闭它。
  Mosh 窗格没有自己的 SSH 通道：它的监控栏通过 SFTP 伴随连接显示，只要该连接处于打开状态。
- **查找**（⌘F）：增量搜索，可切换区分大小写和正则表达式，并显示匹配计数。
- **关键词高亮**：错误、警告、OK/done、IP 地址、URL 和大小（`512M`、`3.2GB`）会在输出到达时着色，
  颜色取自终端主题，因此在任何配色下都清晰可读。“设置”→“功能”→*关键词高亮*可将其关闭；
  *规则…*会打开规则表——每条规则包括文本或正则表达式、是否忽略大小写、颜色、可选背景色、粗体和下划线；
  *恢复默认值*会还原内置规则集。规则重叠时，先匹配者优先，其次是较长的匹配。
  会话的“终端”标签页可以强制开启或关闭（*关键词高亮：默认 / 开启 / 关闭*）。
  只扫描新写入的行（vim 等全屏应用不受影响）；每个终端最多保留 2,000 处标记——输出量大时最旧的行先恢复为普通文本——
  ⌘K 会全部清除。
- **Zmodem（rz/sz）**：直接通过终端传输文件，这是在无法使用 SFTP 的串口控制台或跳板机上的经典做法。
  在远程主机上运行 `sz file …` 可下载到 Mac，运行 `rz` 则从 Mac 上传；MobAlt 会在数据流中识别传输，
  暂停终端，并在 SFTP 面板的传输列表（带“取消”按钮）和状态栏计数器中显示。下载的文件保存到
  下载文件夹（“设置”→“通用”），未设置时则保存到你选择的文件夹；上传会打开文件选择器。
  适用于 SSH、本地、telnet 和串口窗格——不适用于 Mosh（其数据流属于 mosh 客户端，而非原始字节流）。
  可在“设置”→“功能”→“传输”→*Zmodem 传输（rz/sz）*中关闭（默认开启）；关闭后，`rz`/`sz` 的字节
  会像以前一样显示为乱码。在窗格中按 Ctrl-C 或在列表中点按“取消”即可结束传输：远程的 `sz`/`rz`
  会被告知停止，仍在传输途中的数据会被吞掉而不会显示出来，提示符在一秒内恢复；远程 `sz` 意外退出时，
  几秒内即可察觉。同名文件第二次下载会存为 `name (1).ext`，并以该名称列出。
- **剪贴板**：选中即拷贝（“设置”→“终端”→“选中即拷贝”）；右键点击即粘贴（⇧+右键点击打开菜单）。
  将文件从 Finder 拖到 SSH 终端上会上传这些文件；拖到本地终端上则粘贴其路径。
- **粘贴保护**：粘贴多行（或超过 1000 个字符）的内容时会先询问——*要将 N 行粘贴到 … 吗？*
  会在可编辑的预览中显示文本；⌘⏎ 粘贴，Esc 取消。每次粘贴还会检查剪贴板里看不到的内容：
  零宽字符和双向文本控制符、不换行空格（看起来是空格，对 Shell 来说却是单词的一部分）、控制字符、
  末尾换行符（最后一行会立即执行）、行内回车符、`curl … | sh`、对 `~/.zshrc` 等文件或
  `~/.ssh/authorized_keys` 的写入、`rm -rf /` 之类的命令，以及混入西里尔或希腊形似字母的拉丁字母单词。
  检查结果会列出并在预览中标记；*清理后粘贴*会去除隐藏字符和末尾换行符，*原样粘贴*则不加改动地发送文本。
  这两项检查都是“设置”→“功能”→“粘贴保护”中的开关（默认开启）；它们适用于 ⌘V、右键点击以及
  拖到窗格上的文本，不适用于宏。开启 MultiExec 时，一次确认即可覆盖所有可见终端。
- **按键**：Shift+Enter 和 Option+Enter 发送 ESC+CR——即 Claude Code 自己的 `/terminal-setup` 在其他终端中绑定的序列——
  因此这两个键都会在 Claude Code 的输入框中换行，而不是发送提示；Option 键默认用作 Meta。
- **Claude Code 中的图片**：当剪贴板中只有图片而没有文本时（截屏、*拷贝图像*），⌘V、“编辑”→“粘贴”和右键点击粘贴
  都会向终端发送 Ctrl+V；Claude Code 会自行读取系统剪贴板，并将图片附加为 `[Image #1]`。剪贴板中的文本照常粘贴
  （两者都有时以文本为准）；Shell 不使用这个键，因此什么也不显示。从 Finder 拖到本地窗格上的图片文件会粘贴其加引号的路径
  （拖到 SSH 窗格上的文件会被上传，见上文“剪贴板”）。
- **日志**：“终端”→“开始/停止会话日志”或会话选项会将原始输出写入 `~/Documents/MobAlt Logs/`。
  “设置”→“日志”→*从会话日志中去除颜色和控制序列*会改为以纯文本保存日志
  （去除 ANSI 颜色、光标移动和文件夹跟踪钩子）。
- **主题和外观**：“设置”→“终端”→“主题”为整个程序着色，而不只是终端。工具栏、边栏、标签页、
  状态栏、对话框、菜单、提示消息和横幅都会采用由所选主题派生的界面配色——*Moba Dark* 是熟悉的深色界面，
  *Light* 是面板近乎白色、文字为深色的浅色界面，*One Dark*、*Dracula*、*Solarized Dark* 和
  *Gruvbox Dark* 则以各自的色调为界面着色——原生控件和标题栏也会随之变化。在每个主题中，
  界面中的所有文字颜色与其背景的对比度都至少为 4.5:1。主题选择框会以该配色自身的颜色显示示例提示符；
  点按“存储”立即应用。“设置”→“终端”→“字体”适用于所有终端；会话可以在其“终端”标签页中
  覆盖主题和字体——它自己的主题只为该窗格的终端着色，窗口仍使用全局主题。

## 文件（SFTP / FTP）

![SFTP 面板](images/sftp-panel.png)

**SFTP** 面板跟随当前的 SSH 或 FTP 窗格。连接时会自动打开
（“设置”→“通用”→“SSH 连接后切换到 SFTP 面板”）。

- 连按文件夹、输入路径（支持 `~`）或使用 ⬆ / 🏠 / ⟳ 进行浏览。
  “跟随终端”会让面板始终显示 Shell 的当前目录（需要开启会话选项，该选项会注入一个小的提示符钩子）。
  `>_` 会向终端发送 `cd`。
- 工具栏和上下文菜单：新建文件夹、重新命名、权限、删除、下载、上传。用 ⌘ / ⇧ 多选。
  将文件从 Finder 拖到列表上即可上传；名称已存在时会在覆盖前询问。
- 连按文本文件即可在内置编辑器中编辑（⌘S 存储回服务器）。“在外部编辑器中编辑”会用你的编辑器
  （“设置”→“通用”→“外部编辑器”）打开文件，并在每次存储时重新上传。
- 传输会显示进度、速度和取消按钮；下载完成后可选择“在 Finder 中显示”。
- 点按列标题可按名称、大小或日期排序。边栏较窄时会隐藏日期列。

## 隧道（端口转发）

![隧道](images/tunnels.png)

`隧道`（⇧⌘U）用于管理 SSH 端口转发：

- **本地（-L）**：经由 SSH 主机的 `127.0.0.1:8080 → db.internal:5432`。
- **远程（-R）**：将服务器上的端口转发回本地服务。
- **动态（-D）**：经由服务器的本地 SOCKS5 代理。

可以通过已打开的连接启动隧道，也可以让 MobAlt 为已存储的会话打开一条专用连接。
列在会话**隧道**标签页中的隧道会在该会话连接时自动启动；如有隧道无法绑定，会通知你。

## X11、Mosh、串口、RDP/VNC

- **X11**：在“SSH 高级”中勾选“X11 转发”。MobAlt 会在需要时启动 XQuartz、转发显示并替换认证 cookie，
  因此 `xeyes` 或 `gedit` 可以直接运行。状态栏会显示 X11 是否可用。
- **Mosh**：本地需要 `brew install mosh`，主机上需要 `mosh-server`（UDP 60000-61000）。
  窗格中运行的是 mosh 客户端；SSH 引导使用你的密钥、代理或交互式提示。
  如果 `mosh-server` 不在远程主机的 PATH 中，请设置其路径。
- **Mosh + SFTP**：mosh 不提供 SFTP 通道，因此 SFTP 面板通过到同一主机的另一条不带 Shell 的 SSH 连接
  浏览 Mosh 主机（使用相同的密钥、代理和提示）。如果会话开启了“自动打开 SFTP 浏览器”
  （并且“设置”→“通用”中开启了“SSH 连接后切换到 SFTP 面板”），它会自动打开；否则可通过面板中的
  “为此主机打开 SFTP（通过 SSH）”按钮或窗格菜单中的“打开 SFTP 浏览器”打开；它会随窗格一起关闭。
- **串口**：编辑器会列出 USB 串口设备；可设置波特率、数据位/停止位、校验位、流控制、
  本地回显以及 Enter 发送的内容（CR、LF、CRLF）。
- **RDP / VNC**：MobAlt 会写入一个 `.rdp` 文件并打开 Windows App，或在“屏幕共享”中打开 `vnc://`。
  会话像其他书签一样保存主机、用户和文件夹。

## 工具和宏

- **工具**面板：Ping、路由跟踪、DNS 查询、端口扫描和本地网络信息，长时间运行时可点按“停止”按钮。
- **Wake-on-LAN**（工具面板）：以任意写法输入 MAC 地址（`aa:bb:cc:dd:ee:ff`、
  `aa-bb-…`、`aabb.ccdd.eeff` 或纯十六进制）并点按“唤醒”：魔术包会以 UDP 广播发送三次
  （默认 255.255.255.255、端口 9；定向广播如 192.168.1.255 可到达其他子网）。
  最近 10 个地址会连同可选标签被记住，并在你输入时提供建议。
- **网络扫描**（工具面板）：扫描 CIDR（`192.168.1.0/24`）、地址范围（`10.0.0.1-10.0.0.50`
  或 `10.0.0.1-50`）或单个主机，最大 /16，方式为 ICMP ping 和/或对一小组端口
  （默认 22、80、443、3389、5900）进行 TCP 连接，可调整并发数和超时，并对每个响应主机进行反向 DNS 查询。
  响应的主机会在发现时出现在可排序的表格中（IP、主机名、往返时间、开放端口），进度条同时显示
  `123/254` 这样的计数；“停止”可取消扫描，＋ 会打开已填好该主机 SSH 信息的会话编辑器，
  “拷贝为文本”会把表格拷贝到剪贴板。
- **宏**面板：在终端中录制按键（● 录制 / ■ 停止），以某个名称存储，并在当前终端或所有终端中重放。
  文本宏可以直接输入；支持 `\n` 或 `\x1b[A` 之类的转义序列。

## 工作区和设置

MobAlt 会在下次启动时恢复你的标签页、拆分布局和会话（分离到独立窗口的标签页会以窗口形式恢复），
并重新连接 SSH 会话（本地 Shell 会在上次所在的文件夹中重新打开）。可在“设置”→“通用”→“行为”中关闭此功能。

![设置](images/settings.png)

“设置”有五个标签页，每个都能在最小的窗口中无需滚动完整显示：**通用**
（界面语言、退出确认、SFTP 面板切换、工作区恢复、本地 Shell 及其文件夹集成、外部编辑器、下载文件夹、
SSH 保活，以及显示所有数据存储位置的“打开配置文件夹”）、**终端**（字体、行高、光标、回滚行数、
主题——即整个窗口的外观，请参阅*主题和外观*——鼠标/按键，以及*取消拆分*如何处理拆分标签页中的其他窗格：
移为各自的标签页、关闭它们，或每次询问）、**功能**（粘贴保护、远程监控栏及其刷新间隔、
关键词高亮及其规则表，以及 Zmodem 传输）、**日志**（日志文件夹、纯文本会话日志）和**更新**
（启动时检查和“立即检查”）。

### 界面语言

MobAlt 的菜单、工具栏、面板、对话框和消息提供十一种语言：English、한국어、简体中文、日本語、
Tiếng Việt、हिन्दी、Deutsch、Français、Español、Português 和 العربية（阿拉伯语会左右镜像窗口：边栏位于右侧，
文字右对齐；终端仍保持从左到右）。默认情况下（**系统默认**），界面跟随
macOS 的语言列表（“系统设置”→“通用”→“语言与地区”）：采用该列表中第一个 MobAlt 提供的语言，
都不提供时使用英文。“设置”→“通用”→**语言**可以明确指定一种语言；更改会在所有窗口中立即生效——
无需重新启动，连接保持不断——并会被记住。终端输出永远不会被翻译：远程主机打印的内容按原样显示。
用户指南同样提供这十一种语言（`docs/USER_GUIDE.<language>.md`）；“帮助”→**用户指南**会打开当前语言的版本。

在阿拉伯语下，整个窗口从右向左排列：侧边条和边栏移到右边缘，终端移到左侧，边栏的 ‹ 隐藏按钮指向相反方向；
工具栏、标签栏（第一个标签页位于最右侧，其 ‹ › 滚动按钮互换）、状态栏、面板标题、窗格标题栏和监控栏都会镜像；
对话框将标签放在右侧、✕ 放在左侧，菜单向指针左侧展开，提示消息堆叠在左下角。保持从左到右的有：终端本身，
以及所有包含主机、端口、路径、命令、匹配模式、MAC 或 CIDR、密钥或快捷键的字段和标签（快速连接框、SFTP 路径、
查找框、工具面板中的输入框、状态栏中的文件夹和 user@host、按键标记、指纹、密钥生成器中的公钥、粘贴保护预览）；
会话、标签页或文件夹的名称按其首字母决定方向，因此阿拉伯文名称从右向左显示，而 `user@host` 从左到右，
消息中引用的路径或主机名也保持其自身的顺序。拆分保持其物理含义——“向右拆分”仍在右侧打开新窗格，
拖到窗格右边缘的会话也会落在那里。方向键遵循内容的顺序而非屏幕方向：→ 移到下一个标签页、选项或行
（在阿拉伯语下即其左侧的那一个），← 移到上一个；在会话树中，→ 展开文件夹，← 折叠文件夹，与英文相同。

如果想临时以某种语言运行 MobAlt 而不更改设置（截图、测试），可以在环境变量中设置 `MOBALT_LANG=<code>`
后启动（`en`、`ko`、`zh-CN`、`ja`、`vi`、`hi`、`de`、`fr`、`es`、`pt`、`ar`）。

## 数据与隐私

所有数据都保存在 `~/Library/Application Support/MobAlt/` 中：`sessions.json`（密码和密码短语
通过 macOS 钥匙串加密）、`settings.json`、`known_hosts`、`workspace.json` 以及 zsh 集成文件。
会话日志保存在 `~/Documents/MobAlt Logs/`。MobAlt 只连接你配置的主机；可选的更新检查只读取 GitHub 上的
发布列表，不读取其他任何内容。详情请参阅：[SECURITY.md](../SECURITY.md)。

## 故障排除

- **“Timed out while waiting for handshake”/ ETIMEDOUT**：该端口没有任何响应。请检查地址、VPN
  和路由器的端口转发；可在本地终端中尝试 `nc -vz host port`。
- **“身份验证失败——服务器接受：…；已尝试：…”**：服务器没有接受 MobAlt 提供的方式。
  将“接受”列表与会话的身份验证方式进行比较；对于只允许密钥的服务器，请选择正确的密钥文件。
  反复失败可能会导致你的 IP 被 fail2ban 或 sshd 的按来源惩罚机制封禁一段时间。
- **“没有匹配的算法（密钥交换 / 主机密钥 / 加密算法 / MAC）：此会话提供 …；服务器提供 …”**：
  双方没有共同支持的算法。消息中会列出服务器支持的算法：在“SSH 高级”→“算法”中加入其中之一
  （或*重置为默认值*）；对于只支持 SHA-1 / CBC 的老旧设备，请勾选“旧版算法（旧设备）”。
- **主机密钥已更改**：服务器已重装，或有东西在拦截连接。只有在你清楚原因时才接受；
  旧密钥可以从配置文件夹中的 `known_hosts` 里删除。
- **X11 应用没有出现**：安装 XQuartz，并确保远程 Shell 的启动文件没有覆盖 `DISPLAY`。
- **Mosh**：“找不到 mosh 客户端”表示本地缺少 `brew install mosh`；
  “mosh-server not found”表示主机上没有安装 mosh-server，或它不在 PATH 中（请在会话中设置路径）。
- **自行构建的应用出现 Gatekeeper 警告**：右键点击 →“打开”一次，或运行
  `xattr -dr com.apple.quarantine /Applications/MobAlt.app`。
- **`brew upgrade --cask mobalt` 报告 `hdiutil: attach failed – Resource busy`**：另一个 Homebrew 进程
  （例如 `brew audit` 或 `brew fetch`）当时正挂载着同一个 DMG。重新运行该命令即可。
